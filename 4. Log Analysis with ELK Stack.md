# Simple Log Analysis with ELK Stack (Elasticsearch, Logstash, Kibana)

## Introduction
In this project, we will learn the basics of log analysis using the ELK Stack, a popular open-source suite for managing and analyzing log data. The ELK Stack consists of Elasticsearch (for storing and searching data), Logstash (for processing and ingesting data), and Kibana (for visualizing data). By the end of this project, we will be able to set up the ELK Stack, ingest log data, and create visualizations to analyze the data.

## Pre-requisites
- Basic understanding of log files and log management
- Familiarity with Linux command line
- A Linux machine
- Java installed on the machine

## Lab Set-up and Tools
- Parrot OS
- [Elasticsearch](https://www.elastic.co/downloads/elasticsearch) installed
- [Logstash](https://www.elastic.co/downloads/logstash) installed
- [Kibana](https://www.elastic.co/downloads/kibana) installed
- Sample log files for analysis

## Exercises

### Exercise 1: Installing Elasticsearch

**Steps:**

1. Download and install Elasticsearch:
    ```bash
    wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-7.12.1-amd64.deb
    sudo dpkg -i elasticsearch-7.12.1-amd64.deb
    ```
2. Start the Elasticsearch service:
    ```bash
    sudo systemctl start elasticsearch
    sudo systemctl enable elasticsearch
    ```

    <img width="1136" height="394" alt="1" src="https://github.com/user-attachments/assets/9e611737-7ea8-4784-b955-782e3118ea7a" />

3. Verify that Elasticsearch is running by accessing `http://localhost:9200` in a web browser.

**Expected Output:**
- Elasticsearch is installed and running, accessible at `http://localhost:9200`.

### Exercise 2: Installing Logstash

**Steps:**

1. Download and install Logstash:
    ```bash
    wget https://artifacts.elastic.co/downloads/logstash/logstash-7.12.1.deb
    sudo dpkg -i logstash-7.12.1.deb
    ```    
3. Configure Logstash by creating a configuration file (`logstash-simple.conf`):
    ```bash
    sudo nano /etc/logstash/conf.d/logstash-simple.conf
    ```

    <img width="648" height="201" alt="2" src="https://github.com/user-attachments/assets/098748a4-e7f1-4cc8-8a22-b71c5fb20ffb" />
    
    Add the following content to the configuration file:
    ```plaintext
    input {
      file {
        path => "/path/to/your/logfile.log"
        start_position => "beginning"
      }
    }
    output {
      elasticsearch {
        hosts => ["localhost:9200"]
      }
      stdout { codec => rubydebug }
    }
    ```

    <img width="555" height="383" alt="3" src="https://github.com/user-attachments/assets/3ad0410d-271c-4a67-bdf5-0616b32ba4b0" />

4. Start the Logstash service:
    ```bash
    sudo systemctl start logstash
    sudo systemctl enable logstash
    ```

    <img width="587" height="252" alt="4" src="https://github.com/user-attachments/assets/3cffa3fd-928f-43d0-8647-a589ed83b8bb" />

**Expected Output:**
- Logstash is installed and configured to ingest log data and send it to Elasticsearch.

1. Ensure that the log file specified in `logstash-simple.conf` exists and contains sample log data.


### Exercise 5: Creating Visualizations in Kibana

**Steps:**

1. Open Kibana in a web browser (`http://localhost:5601`).
2. Configure an index pattern to match the log data indexed by Logstash:
    - Navigate to "Management" > "Kibana" > "Index Patterns".
    - Create a new index pattern matching the Logstash index (e.g., `logstash-*`).

    <img width="1383" height="755" alt="9" src="https://github.com/user-attachments/assets/b8a65055-3c02-48e0-9f6d-d29bfa997673" />

3. Explore the log data in the "Discover" tab to understand the available fields and data.

    <img width="1396" height="818" alt="10" src="https://github.com/user-attachments/assets/7df68262-c1b6-4617-94d8-87bff3b9d4b8" />

4. Create visualizations based on the log data:
    - Navigate to "Visualize" > "Create new visualization".
    - Choose a visualization type (e.g., bar chart, line graph) and configure it using the log data fields.

      <img width="1412" height="823" alt="11" src="https://github.com/user-attachments/assets/2e9c291c-1973-40a5-a468-f5b56d99fdca" />

5. Save the visualizations and add them to a new dashboard in Kibana.

**Expected Output:**
- Visualizations created in Kibana, providing insights into the log data, with a dashboard displaying various visualizations.

By completing these exercises, we will gain hands-on experience in setting up and using the ELK Stack for log analysis, including installing and configuring Elasticsearch, Logstash, and Kibana, ingesting log data, and creating visualizations to analyze the data.
