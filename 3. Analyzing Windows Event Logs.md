# Analyzing Windows Event Logs for Security Incidents

**Focus:** Event analysis • Authentication monitoring • Endpoint telemetry • SIEM fundamentals

This case study presents a practical log-analysis workflow, organised around the objective, procedure, evidence, and interpretation.

**Focus:** Event analysis • Authentication monitoring • Endpoint telemetry • SIEM fundamentals

This case study provides a practical workflow for security and system log analysis. It is organised around the investigation objective, method, evidence, and findings.

## Prerequisites
- Basic understanding of Windows operating system and administration
- Familiarity with Windows Event Viewer
- A Windows machine (Windows 10 or later)

## Lab Environment and Tools
- Windows 10 or later
- Access to Event Viewer
- Event Log Explorer

## Procedure

### Step 1: Accessing Windows Event Logs

**Steps:**

1. Open Event Viewer by pressing `Win + R`, typing `eventvwr`, and pressing `Enter`.

    <img width="486" height="304" alt="1" src="https://github.com/user-attachments/assets/aa4a1a65-7369-4545-9e16-0cebe7cebfb4" />

2. In the Event Viewer console, expand "Windows Logs" and select "System".

    <img width="1920" height="1016" alt="2" src="https://github.com/user-attachments/assets/64e49e68-8af5-4ec7-9d83-1f531dae3844" />

3. Review the list of system events to understand the types of logs generated by the operating system.

**Expected result:**
- Access to the System event logs, with an understanding of the different types of events recorded.

### Step 2: Understanding Security Event Logs

**Steps:**

1. In the Event Viewer console, expand "Windows Logs" and select "Security".

    <img width="1920" height="1022" alt="3" src="https://github.com/user-attachments/assets/c72959d8-2e6a-4492-a035-8eaed4cdc1c7" />

2. Review the list of security events, focusing on events related to logon attempts, account management, and policy changes.  
3. Identify key event IDs that are commonly associated with security incidents (e.g., 4624 for successful logon, 4625 for failed logon).
   
**Expected result:**
- Understanding of the types of events recorded in the Security logs, including logon attempts and account management events.

### Step 3: Filtering and Searching Event Logs

**Steps:**

1. In Event Viewer, use the "Filter Current Log" option in the right-hand pane.
2. Filter Security logs to show only events with a specific Event ID (e.g., 4625 for failed logon attempts).

    <img width="1920" height="1023" alt="4 1" src="https://github.com/user-attachments/assets/8799fca6-1e16-44a1-bf0b-058ffefa23df" />    
    
3. Use the "Find" option to search for events related to a specific user or computer.

**Expected result:**
- A filtered view of event logs showing specific security events, demonstrating how to narrow down log data to relevant incidents.

### Step 4: Analyzing Event Details

**Steps:**

1. Select a security event (e.g., a failed logon attempt) and review the event details.
2. Note key information such as the date and time, user account involved, source IP address, and any error codes.
3. Correlate multiple events to understand the sequence of actions (e.g., multiple failed logon attempts followed by a successful logon).

    <img width="1920" height="1018" alt="4" src="https://github.com/user-attachments/assets/b0c45efe-91a7-489f-80d1-17921b117bce" />

**Expected result:**
- Detailed analysis of specific security events, including key information and correlations between related events.

**Steps:**

1. Download and install Event Log Explorer.

    <img width="784" height="554" alt="5" src="https://github.com/user-attachments/assets/ab2404fa-e3ca-4c1b-8b34-0633c80ed2ab" />

    <img width="1358" height="1017" alt="6" src="https://github.com/user-attachments/assets/f4a82ff5-44a9-48f5-8d49-8d1349c3a344" />

3. Use filter to analyze log data, such as identifying the top sources of failed logon attempts.  

    <img width="1389" height="1022" alt="9" src="https://github.com/user-attachments/assets/348c9107-bd45-447c-936a-9e635f33993f" />

4. Customize and run additional queries to extract specific information from the logs.

**Expected result:**
- Advanced analysis of event logs using Event Log Explorer, with queries that extract and summarize key information from security events.

By completing these exercises, we will gain hands-on experience in accessing, filtering, and analyzing Windows Event Logs to detect and investigate security incidents. These skills are essential for effective incident response and system security monitoring.
