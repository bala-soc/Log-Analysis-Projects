## Skills Covered
- Filtering and summarising log events
- Investigating Windows and Linux authentication activity
- Reviewing process and network telemetry
- Recognising unusual web requests and event patterns
- Ingesting and exploring logs with ELK

## What to Include in Each Case
- Scenario and investigation question
- Environment, log source, and sample-data provenance
- Commands or queries used
- Sanitised evidence and relevant timeline
- Analyst conclusion, limitations, and recommended next steps
- Test cases and potential false positives, where relevant

## Tools
Windows Event Viewer, Sysmon, Linux syslog, Apache logs, Elasticsearch, Logstash, Kibana, and relevant command-line utilities.

> Use authorised systems and safe sample data. State whether results were observed during a lab run or are expected outcomes from a tutorial. Avoid including secrets or personal data in logs and screenshots.
