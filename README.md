# Log Analysis Projects

This repository contains hands-on projects focused on Log Analysis

The goal of this repository is to demonstrate practical SOC Analyst (L1) vulnerability management, incident response, and log analysis.

---

## Introduction

These projects aim to provide a practical and comprehensive learning experience for those looking to enhance their cybersecurity knowledge and capabilities. Each project includes detailed steps, exercises, and expected outcomes to guide us through the learning process.

---

## 📁 Projects Included

### 1. [Apache Web Server Log Analysis](https://github.com/bala-soc/Log-Analysis-Projects/blob/main/1.%20Apache%20Web%20Server%20Log%20Analysis.md)
Apache logs are a rich source of information about web traffic and can help identify potential security incidents, usage patterns, and performance issues.

**Key Focus Areas:**
- Accessing Apache Log Files
- Understanding Access Logs
- Filtering Log Entries
- Analyzing Error Logs
- Summarizing Log Data

---

### 2. [Syslog Analysis on Linux Systems](https://github.com/bala-soc/Log-Analysis-Projects/blob/main/2.%20Syslog%20Analysis%20on%20Linux%20Systems.md)
Syslog is a standard logging protocol used to collect and store log messages from various system processes and applications.

**Key Focus Areas:**
- Understanding Syslog Configuration
- Accessing Syslog Files
- Filtering Syslog Entries
- Analyzing Authentication Logs
- Summarizing Log Data

---

### 3. [Analyzing Windows Event Logs for Security Incidents](https://github.com/bala-soc/Log-Analysis-Projects/blob/main/3.%20Analyzing%20Windows%20Event%20Logs.md)
Windows Event Logs are a valuable source of information about system activities, user actions, and potential security issues.

**Key Focus Areas:**
- Accessing Windows Event Logs
- Understanding Security Event Logs
- Filtering and Searching Event Logs
- Analyzing Event Details
- Advanced Log Analysis with Event Log Explorer

---

### 4. [Log Analysis with ELK Stack](https://github.com/bala-soc/Log-Analysis-Projects/blob/main/4.%20Log%20Analysis%20with%20ELK%20Stack.md)
The ELK Stack consists of Elasticsearch (for storing and searching data), Logstash (for processing and ingesting data), and Kibana (for visualizing data).

**Key Focus Areas:**
- Installing Elasticsearch
- Installing Logstash
- Installing Kibana
- Ingesting Log Data with Logstash
- Creating Visualizations in Kibana

---

### 5. Analyzing Windows Sysmon Events for Security Incidents

**Key Focus Areas:**
- Verify Sysmon Installation and Configuration
- Analyze Process Creation Events
- Monitor Network Connections
- Investigate File Creation Events
- Detecting Image Load Events

---

## 🎯 Objective
The objective of this repository is to:
- To perform basic host-based incident response using Sysinternals tools.
- To identify suspicious processes, persistence mechanisms, and network activity.
- To gain hands-on experience with endpoint investigation techniques.
