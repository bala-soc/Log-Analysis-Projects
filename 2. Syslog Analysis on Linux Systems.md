# Syslog Analysis on Linux Systems

**Focus:** Event analysis • Authentication monitoring • Endpoint telemetry • SIEM fundamentals

This case study presents a practical log-analysis workflow, organised around the objective, procedure, evidence, and interpretation.

**Focus:** Event analysis • Authentication monitoring • Endpoint telemetry • SIEM fundamentals

This case study provides a practical workflow for security and system log analysis. It is organised around the investigation objective, method, evidence, and findings.

## Prerequisites
- Basic understanding of Linux system administration
- Familiarity with Linux command line
- A Linux machine

## Lab Environment and Tools
- Parrot OS (or any Linux distribution with syslog configured)
- Access to syslog files (typically located in `/var/log/`)

## Procedure

### Step 1: Understanding Syslog Configuration

**Steps:**

1. Open the syslog configuration file using a text editor:
   
    ```bash
    sudo nano /etc/rsyslog.conf
    ```

    <img width="1384" height="740" alt="1 1" src="https://github.com/user-attachments/assets/3df16838-20f9-460e-b168-430a463f8b67" />
    
3. Review the configuration directives to understand how syslog is set up.
4. Identify the different logging facilities and their corresponding log files.

**Expected result:**
- A basic understanding of the syslog configuration, including logging facilities and their destinations.

### Step 2: Accessing Syslog Files

**Steps:**

1. Navigate to the syslog directory:
    ```bash
    cd /var/log/
    ```

    <img width="630" height="254" alt="1" src="https://github.com/user-attachments/assets/52ab2005-0e52-4002-91e9-31670508f8f0" />
    
2. List the available syslog files to understand the different log files generated by the system:
    ```bash
    ls -l
    ```

    <img width="921" height="951" alt="2" src="https://github.com/user-attachments/assets/f1663ca4-2496-4d0c-a2f3-df26f7dcfe22" />

3. Open the main syslog file using `less` or `cat`:
    ```bash
    less syslog
    ```

    <img width="1610" height="573" alt="3" src="https://github.com/user-attachments/assets/c73dd29a-7f30-43b6-a529-4f4f019a9160" />

**Expected result:**
- A list of syslog files, with an initial look at the contents of the main syslog file.

### Step 3: Filtering Syslog Entries

**Steps:**

1. Use the `grep` command to filter syslog entries based on specific criteria, such as a particular date:
    ```bash
    grep 'Dec 18' syslog
    ```

    <img width="1608" height="582" alt="4" src="https://github.com/user-attachments/assets/6876ed3b-380e-4620-9f6c-5d4b3e0c1c6c" />

2. Filter log entries by a specific process or service (e.g., sshd):
    ```bash
    grep 'sshd' syslog
    ```

    <img width="1620" height="349" alt="5" src="https://github.com/user-attachments/assets/8e0580bf-36a1-445d-8712-711d7bb731d6" />

3. Combine filters to extract more specific information, such as sshd logins on a particular date:
    ```bash
    grep 'Dec 18' syslog | grep 'sshd'
    ```

   <img width="1613" height="354" alt="6" src="https://github.com/user-attachments/assets/9936d64a-feee-4408-867d-03e05bb591dd" />

**Expected result:**
- A filtered list of syslog entries matching the specified criteria, demonstrating how to extract specific information from log files.

### Step 4: Analyzing Authentication Logs

**Steps:**

1. Open the authentication log file using `less` or `cat`:
    ```bash
    less auth.log
    ```

    <img width="1513" height="591" alt="7" src="https://github.com/user-attachments/assets/0cca4ca8-ff9d-467f-82ef-10f7ebcdf06b" />

2. Identify different types of authentication events, such as successful logins, failed login attempts, and user changes.
3. Note the timestamps, usernames, and source IP addresses for each event.

**Expected result:**
- Insight into the types of authentication events logged in the authentication log, including successful and failed login attempts.

### Step 5: Summarizing Log Data

**Steps:**

1. Use the `awk` command to summarize log data, such as counting the number of login attempts from each IP address:
    ```bash
    awk '/sshd/ && /Failed password/ {print $11}' auth.log | sort | uniq -c | sort -nr
    ```

    <img width="962" height="308" alt="8" src="https://github.com/user-attachments/assets/8855de24-9ae8-4c37-96f5-b48ad34ca260" />
    
2. Summarize the number of successful logins per user:
    ```bash
    awk '/sshd/ && /Accepted password/ {print $9}' auth.log | sort | uniq -c | sort -nr
    ```

    <img width="931" height="249" alt="9" src="https://github.com/user-attachments/assets/1ccad8e7-044d-44a7-b5e1-2fc83123f553" />

3. Identify the most frequent types of syslog messages:
    ```bash
    awk '{print $6}' syslog | sort | uniq -c | sort -nr
    ```

    <img width="766" height="443" alt="10" src="https://github.com/user-attachments/assets/5347a55d-6bd6-4fe9-8242-953fb4babdb9" />

**Expected result:**
- Summarized log data showing the number of login attempts per IP address, successful logins per user, and the most frequent types of syslog messages.

By completing these exercises, we will gain hands-on experience in accessing, filtering, and analyzing syslog files on Linux systems, which are essential skills for system troubleshooting and security monitoring.
